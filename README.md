# Birthday Gift — Salwa Safitri ♡

Website ucapan ulang tahun bernuansa romantis pink aesthetic.

## Isi folder
- `index.html` — struktur website dan pesan.
- `style.css` — desain, warna, animasi, dan tampilan responsif.
- `script.js` — interaksi tombol, hadiah, musik, dan animasi.
- `images/` — tempat foto kenangan.
- `music/` — tempat file musik.

## Personalisasi foto dan musik
1. Masukkan hingga 3 foto ke folder `images`.
2. Beri nama persis: `foto-1.jpg`, `foto-2.jpg`, dan `foto-3.jpg`.
3. Masukkan file musik MP3 ke folder `music` dan beri nama `lagu.mp3`.
4. Jika tidak menambahkan foto atau musik, website tetap bisa dibuka; foto akan menampilkan placeholder dan musik memberi pemberitahuan.

Gunakan foto dan musik yang memang boleh kamu bagikan.

## Upload ke GitHub Pages
1. Login ke https://github.com lalu buat repository baru bernama `birthday-gift`.
2. Pilih **Public**, lalu buat repository.
3. Buka repository, pilih **Add file → Upload files**.
4. Unggah seluruh isi folder ini (bukan hanya file ZIP), termasuk `index.html`, `style.css`, `script.js`, folder `images`, dan `music`.
5. Tekan **Commit changes**.
6. Buka **Settings → Pages**.
7. Pada **Build and deployment**, pilih **Deploy from a branch**.
8. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
9. Tunggu beberapa menit. Alamat situs biasanya:
   `https://USERNAME.github.io/birthday-gift/`
   Ganti `USERNAME` dengan username GitHub kamu.

## Catatan
- File utama wajib bernama `index.html` dan berada di root repository.
- Musik tidak diputar otomatis; pengunjung perlu menekan tombol Putar musik.
- Untuk mengganti tulisan, edit teks di bagian `letter-text` pada `index.html`.
